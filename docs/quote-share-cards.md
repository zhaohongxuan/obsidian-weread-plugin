# 分享阅读卡片

在今日、回顾、那年今日、旧句重逢、收藏，以及书籍详情的划线、热门划线、想法和书评中，点击正文旁的分享图标，打开同一个卡片预览组件。收藏列表即使折叠成摘要，分享也会保留完整正文；想法包含对应引文，书评保留标题和原作者来源。分享采用点击时的内容快照，不修改原笔记、收藏或微信读书数据。

所有模板以「分享此刻」为通用标题，右上角标识为 **OBSIDIAN WEREAD**。没有原始日期的热门划线或本地内容不会生成虚构日期。

提供三种模板：

- **纸间**：默认模板，暖白纸底、宋体书摘与简洁落款。
- **书封**：书籍侧栏与编辑式排版。
- **夜读**：深色背景与柔和的暖色点缀。

卡片显示完整原文、书名、作者、章节、划线日期与用户名，图书封面位于右下角。没有封面或加载失败时使用文字书封。长内容自动增加图片高度，不以省略号截断；超出单张图片安全尺寸时会明确提示。

## 模板与署名

切换预览模板不会自动改掉默认值。点击「设为默认模板」，或在「设置 → Weread → 书架设置 → 分享卡片默认模板」中选择，之后打开分享会使用该模板。

署名默认使用已有的微信读书用户名。可在预览的「分享署名」或设置中的同名字段填写自定义名称；清空后恢复微信读书用户名。未获取昵称且未填写署名时显示「阅读者」。

## 导出

- **复制图片**：将当前预览对应的 PNG 图片复制到剪贴板，可直接粘贴到支持图片的应用。设备不支持或拒绝剪贴板访问时会提示，可改用保存图片或系统分享。
- **保存图片**：导出 PNG 图片到设备支持的下载位置。
- **保存到笔记库**：使用 Obsidian 的附件保存位置；较早版本的 Obsidian 保存到笔记库根目录。已有文件不会被覆盖。
- **系统分享**：设备支持图片文件分享时显示，可调用系统分享面板。

PNG 宽度为 1080 像素，高度随正文调整。预览与导出使用同一张图片，切换模板、署名或书封加载完成后会更新预览。

「旧句重逢包含公众号」统一放在插件设置中，保留原有选择。该选项只影响旧句推荐，不改变公众号笔记同步、完整回顾列表或收藏。
