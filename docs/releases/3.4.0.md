# 3.4.0 · 阅读工作台与精准原文定位

本次更新统一原文阅读入口，改进收藏卡片、书籍详情与阅读统计，并更新 README 的原生界面截图。包含 3.3.1 已发布的同步可靠性、章节评论标题和兼容性修复。

## 原文阅读与定位

- 今日、回顾、收藏和书籍详情遵循「阅读入口」设置：网页版使用配置的标签页或独立窗口，App 使用 deeplink。
- 修复章节较深处的划线只打开章节开头的问题。定位以实际阅读正文或 Canvas 已绘制文字为依据，不再把笔记侧栏或隐藏预排版里的文字误判为成功。
- 支持横向翻页与纵向阅读，定位成功后自动收起笔记列表，让目标正文直接可见。
- 同章切换划线会重新定位；新请求或关闭阅读器会取消旧查找。无法确认精确位置时明确提示，保留笔记列表供手动选择。

## 更紧凑的阅读工作台

- 收藏卡片采用瀑布流，长短摘录紧密衔接，窗口、字体或内容变化后自动重排。
- 卡片渐变进一步变浅，加入分散的柔和色相；同一条收藏保持稳定配色，搜索或排序时不跳色。
- 收藏搜索框加宽并自适应，图标计数展示收藏条数与去重书籍数，随搜索结果更新。
- 书籍详情的划线与笔记数量移到封面下方；「去阅读」「本地笔记」「刷新」「同步笔记」使用图标加文字。
- 统计热力图缩为紧凑小格，宽屏下阅读时长图表与时长榜并排，窄屏上下排列。
- 主功能 Tab 使用图标与文字，今日/回顾头部和操作区更紧凑，笔记时间显示到时分，并支持按时间正反序浏览。

## 收藏画布目录

- 新增「收藏画布保存目录」，默认笔记库根目录，可配置笔记库内的相对目录。
- 迁移前校验并保存原生草稿；目标已有收藏数据时停止，不覆盖。旧文件和迁移原件保留，支持校验后的安全重试。
- 收藏继续独立于登录和笔记缓存，不会因退出登录、清理缓存或远端变化而自动删除。

## 升级与安装

- 最低要求仍为 **Obsidian 1.1.9**。
- 升级前建议备份笔记库，特别是收藏画布、对应备份和迁移原件。切换收藏目录前，请先保存并关闭已打开的画布。
- 使用发布 ZIP，或下载 `main.js`、`manifest.json`、`style.css` 放入插件目录；保留原有配置与缓存，不要将 `style.css` 改名。
- 插件保持微信读书到 Obsidian 的单向同步，不会把本地笔记修改反向写回微信读书。
