# 3.5.4 · 对齐官方 lint（errors 清零，大幅减少 warnings）

## 变更

- 采用 Obsidian 官方社区插件审查等效的 ESLint 配置（`eslint-plugin-obsidianmd` 0.6 的完整 `recommended`，仅保留 scanner 明确停用的规则）。`npm run lint` 现在如实反映 https://community.obsidian.md 的评分口径；新增 `lint:fix` 用于自动修复，`build` 不再串联 lint。
- **Errors 135 → 0**：
  - `no-unnecessary-type-assertion`（52）：删除多余的类型断言。
  - `no-floating-promises`（26）：补齐 `void` 或 `.catch`。
  - `no-console`（46）：`console.log/info` 改为 `console.debug`（保留 warn/error/debug）。
  - `no-control-regex`：对有意过滤控制字符的正则加带说明的豁免。
  - 其余：`no-manual-html-headings`、`only-throw-error`、`await-thenable`、`no-useless-escape`、`depend/ban-dependencies`（显式允许 crypto-js）。
- **Warnings 显著减少**（DOM/环境类全部真修）：
  - `prefer-create-el` / `prefer-window-timers` / `prefer-active-doc` / `prefer-instanceof`：改用 Obsidian 的 `createEl`/`window.*`/`activeDocument`/`instanceOf`。
  - 同步完善测试基建（Chrome harness 与 Node 测试补齐相应全局），保证全部回归通过。
- 剩余 warnings 仅为 `no-explicit-any`（WeRead API 松散类型，按计划暂留）及少量有意保留项（`no-deprecated`、`no-alert`、`prefer-setting-definitions`）。

## 升级说明

- 最低要求仍为 Obsidian **1.1.9**；本次为内部质量/审查对齐，无功能变更。
- 手动安装时只替换 `main.js`、`manifest.json`、`style.css` 三个运行文件，保留 `data.json`、笔记缓存及收藏 Canvas。
