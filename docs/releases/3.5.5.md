# 3.5.5 · 进一步收紧类型（no-explicit-any 65 → 37）

## 变更

- 清理安全的显式 `any` 断言（65 → 37），无功能变更：
  - 统计视图：为运行时缓存字段新增 `ReadingStatsResponseWithCache` 类型，替代 `(data as any).*`；`userInfo` 用字符串类型守卫；导出弹窗 `App` 类型化。
  - `main.ts`：`(x as any)` 改为精确的 `unknown` 接口断言（`app.setting` / `view.contentEl` / 隐藏窗口）。
  - `api.ts`：`catch (e)` + 窄化 `{message,status}`。
  - 模板编辑器：`Component` 断言 + `Error instanceof` 窄化。
  - 登录/注销/浏览器窗口：`modal` 标注为 electron `BrowserWindow`，`webRequest` 回调用 Electron 详情类型，`require('electron').remote` 显式断言。
- 剩余的 `no-explicit-any`（37）为 WeRead API 数据模型（`models.ts`/`api-v2.ts`）与模块声明（`index.d.ts`）等，按计划保留，避免大范围类型重构的运行时风险。

## 升级说明

- 最低要求仍为 Obsidian **1.1.9**；无功能变更。
- 手动安装只替换 `main.js`、`manifest.json`、`style.css`。
