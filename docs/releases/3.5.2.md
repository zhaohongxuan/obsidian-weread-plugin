# 3.5.2 · 版本号与发布对齐

## 说明

- 本次为维护性发布，将 manifest 版本号推进到 `3.5.2`，修复商店/安装端提示「No release matches your manifest version」的版本匹配问题。
- GitHub Release 的 tag 与 `manifest.json` 中的版本号保持一致（均为 `3.5.2`，不带 `v` 前缀），确保 Obsidian 能按版本号找到对应的发布资源。

## 升级说明

- 最低要求仍为 Obsidian **1.1.9**。更新插件后重载插件或重新打开 Obsidian 即可。
- 手动安装时只替换 `main.js`、`manifest.json` 和 `style.css` 三个运行文件，保留 `data.json`、笔记缓存及收藏 Canvas。
