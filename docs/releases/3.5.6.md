# 3.5.6 · 提升最低 Obsidian 版本至 1.7.2，清除商店告警

## 变更

- **最低 Obsidian 版本 1.1.9 → 1.7.2**。代码实际使用了 `workspace.revealLeaf`（1.7.2）、`FileManager.trashFile`（1.6.6）、`getAvailablePathForAttachment`（1.5.7）、`Vault.createFolder`（1.4.0）等 API，旧的 1.1.9 声明与实际不符，会导致商店 `no-unsupported-api` 告警。
- **文件删除遵循用户偏好**：`deleteNotebookFile` 与热门划线缓存清理改用 `FileManager.trashFile()`（系统/本地回收站按用户设置），不再用 `Vault.trash`/`Vault.delete`。
- **不再使用 `window.confirm`**：模板关闭确认与主题删除确认改用 Obsidian `Modal`（`src/utils/confirmModal.ts`）。
- **修复 `+` 运算的类型问题**：`main.ts` 中 `'...' + e` 改为安全字符串拼接。
- **`require()` 动态导入**（electron / html-to-image）保留并加带说明的豁免；`require('obsidian')` 改为顶层 import。
- 本地 ESLint 配置新增 scanner 的严格层级规则（`no-unsupported-api`、`prefer-create-el`、`no-static-styles-assignment`、`no-require-imports`、`prefer-file-manager-trash-file`、`restrict-plus-operands`、`only-throw-error`、`no-alert` 等），`npm run lint` 更贴近商店评分口径。

## 升级说明

- **最低需要 Obsidian 1.7.2**（用户须升级 Obsidian 才能安装/更新本插件）。
- 手动安装只替换 `main.js`、`manifest.json`、`style.css`。
