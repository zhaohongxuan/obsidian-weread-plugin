# 3.5.3 · 修复商店审查报错并补齐官方 lint

## 修复

- 移除 `manifest.json` 中的非法字段 `requestUrl`，修复社区插件审查提示「Manifest contains unknown fields — requestUrl」。该字段并非 manifest 合法字段（Obsidian 提供的是同名 API 函数，无需在 manifest 中声明）。
- 模板编辑器左侧说明面板不再直接赋值 `innerHTML`，改用 `sanitizeHTMLToDom()` + `appendChild()` 渲染，修复审查提示「Unsafe assignment to innerHTML」（`src/components/templateEditorWindow.ts`）。
- 修复若干 `no-misused-promises` 隐患：对 hydration / inflight / persistence / loading 等 Promise 使用显式 `!== undefined/null` 判断，异步事件与定时器回调改为 `void (async () => {})()` 包装。

## 工具链

- `eslint-plugin-obsidianmd` 升级至 **0.6.0**，`eslint.config.mjs` 改用官方 `recommended` 规则集。本地 `npm run lint` 即可检出 manifest 非法字段（`obsidianmd/validate-manifest`）与不安全 HTML 赋值（`no-unsanitized/property`、`@microsoft/sdl/no-inner-html`），与商店扫描口径对齐。
- 补齐测试所需的 `yaml` 开发依赖（依赖树刷新后不再作为传递依赖存在）。

## 升级说明

- 最低要求仍为 Obsidian **1.1.9**。更新插件后重载插件或重新打开 Obsidian 即可。
- 手动安装时只替换 `main.js`、`manifest.json` 和 `style.css` 三个运行文件，保留 `data.json`、笔记缓存及收藏 Canvas。使用 iCloud 同步的设备请等待插件文件同步完成后再重新打开 Obsidian。

## 验证

- 类型检查（`tsc --noEmit`）与构建通过；`npm run lint` 0 错误。
- 完整 348 项自动化测试通过，0 项跳过（含真实 Chrome UI 回归）。
- Release 产物校验：`manifest.json` 版本 `3.5.3`、无 `requestUrl`；ZIP 内 `main.js`/`manifest.json`/`style.css` 与扁平下载逐字节一致。
