# 3.5.3 · 修复商店审查报错与本地 lint 对齐

## 修复

- **移除 manifest 非法字段 `requestUrl`**：修复社区插件审查提示「Manifest contains unknown fields — requestUrl」。
- **修复不安全的 `innerHTML` 赋值**：模板编辑器左侧说明面板改用 `sanitizeHTMLToDom()` + `appendChild()` 渲染，修复审查提示「Unsafe assignment to innerHTML」（`src/components/templateEditorWindow.ts`）。

## 工具链

- eslint 配置升级为官方 `eslint-plugin-obsidianmd` 0.6 的 `recommended` 规则集，本地即可检出 manifest 非法字段与不安全 HTML 赋值等审查项。
- 顺带修复若干 `no-misused-promises`（Promise 布尔判断与事件/定时器回调），并补齐测试所需的 `yaml` 开发依赖。

## 升级说明

- 最低要求仍为 Obsidian **1.1.9**。更新插件后重载插件或重新打开 Obsidian 即可。
- 手动安装时只替换 `main.js`、`manifest.json` 和 `style.css` 三个运行文件，保留 `data.json`、笔记缓存及收藏 Canvas。
