# 划线收藏：3.1.0 实施方案

状态：按用户授权直接实施。基于 Weread 3.0.0；收藏功能目标版本 3.1.0。

## 产品范围

- 今日、回顾、那年今日和旧句重逢中的**个人划线**支持收藏。想法与社区热门划线本期不开放收藏。
- 日期后的原文、复制图标旁增加星标，未收藏为空心、已收藏为实心。保存期间禁用同来源重复操作，失败保持原状态。
- 导航顺序：今日 / 书架 / 回顾 / 收藏 / 统计。收藏复用现有页面，提供卡片与列表视图、搜索、排序、继续加载、取消与撤销。
- 默认卡片视图，记住最后选择。收藏页离线可用，不依赖笔记扫描或远端请求。

## JSON 与 Canvas

收藏以独立 JSON 为权威数据。Canvas 本身也是 JSON，但主要保存节点、连线和位置，不适合直接承担收藏状态、来源去重与版本恢复。

本期实现 JSON 存储与导出备份，不实现 Canvas。未来可单向导出 Canvas，每条收藏生成一个文本节点；用户编辑导出的画布不会反向修改收藏。Canvas 标准：https://jsoncanvas.org/spec/1.0/ 。

## 数据归属与位置

收藏是**当前笔记库所有者的本地个人集合**，不按登录凭据分库，不随退出登录、换 Key、清笔记缓存而清除或隐藏。来源是收藏当时页面提供的个人划线；收藏库不存 API Key、Cookie 或凭据哈希。

```text
WereadData/favorites/
  favorites.json                   # 主库
  favorites.previous.json          # 上一个有效版本
  favorites.staging.json           # 写入校验用暂存文件，不是主库
  favorites.corrupt.<unique>.json  # 恢复前保留的损坏原件
  favorites.export.<unique>.json   # 用户主动导出的备份
```

- 使用固定的 vault 相对目录，与插件安装目录和书籍同步目录分开。
- 不修改原有书籍 Markdown，不把正文存进插件 data.json；卸载插件不主动删除收藏目录。
- 一期不承诺多设备同时写入的自动合并。vault 在 iCloud 或其他同步目录内时，文件可能随同步工具传播；写前检测外部变更并拒绝静默覆盖，但这不是跨进程锁或 compare-and-swap。
- 多端离线并发、跨账号自动归属识别、同源记录跨库合并属于后续扩展，不能通过凭据哈希推断永久账号身份。

## 数据模型

主文档保存 `schemaVersion: 1`、递增的 `revision` 和 `records`。

每条 FavoriteEntry 保存：

| 字段 | 说明 |
|---|---|
| id | 原始 JournalNote.id，即 bookId:highlight:bookmarkId；同来源去重，不用正文哈希 |
| note | JournalNote 的完整公开字段快照：正文、书籍、作者、封面、章节、划线时间、来源链接 |
| favoritedAt | 收藏时间，毫秒，用于默认排序 |
| updatedAt | 最后操作时间，毫秒 |
| deletedAt | 取消墓碑；不存在时为有效收藏 |

正文保留换行。源划线被编辑、远端未返回、缓存清空或来源不可用，不自动覆盖收藏快照。相同正文但不同来源可以分别收藏。

取消保留墓碑；撤销恢复原快照和收藏时间。普通重新收藏也复用原快照，避免隐式改写已保存的句子。

## 写入与恢复

1. 单例服务先完成本地加载，再接受数据修改。多面板共享一份服务和串行写队列。
2. 每次操作捕获独立快照；读取/订阅返回副本，调用者不能改写内部记录。
3. 写前检查正式文件内容与本地基线一致。不一致时重新加载并提示重试，不覆盖外部修改。
4. 生成新 JSON，写暂存文件并读回验证，再备份上一个有效版本。
5. 再次检查正式文件基线，写正式文件并读回验证。确认完成后更新星标和列表，失败不假报成功。
6. 不能假定移动端 adapter 的重命名具有原子替换语义，因此使用可验证写入与有效前驱备份恢复。
7. 主文件损坏时，先原样保存损坏文件，验证备份后恢复；保留恢复提示。备份也损坏或只有不完整暂存文件时，停止写入。
8. 高于当前支持的 schema 版本只读报错，不能用空库或旧备份覆盖新格式。
9. 导出备份通过同一队列写到独立文件，显示 vault 内路径；不触碰用户剪贴板或上传内容。

## 界面与性能

- 星标状态跨今日/回顾实例同步，局部更新按钮，不触发笔记刷新、随机句子重选或页面滚动重置。
- 收藏页搜索正文、书名、作者与章节；支持按收藏时间或划线时间排序，分批渲染。
- 读取失败、只读、恢复警告、加载中和空列表分别展示。来源链接校验协议，正文使用文本渲染。
- 收藏状态查询使用内存索引，收藏页首次加载后复用内存；不因切 Tab 重新扫描数百本书。
- 单条取消提供限时撤销；面板关闭时清理计时器、订阅和失效界面引用。

## 验证要求

- 重启持久化、重复收藏去重、快照冻结、取消/撤销与墓碑保留。
- 磁盘写入失败、截断 JSON、未来 schema、损坏备份、外部修改、失败后再次操作、关闭时排队操作。
- 源对象修改、无效记录或认证信息不能污染存储；不访问原书籍文件和认证配置。
- 五个 Tab 的惰性加载、键盘导航、筛选与滚动保留、关闭释放。
- 生产渲染器中的星标同步、双视图、搜索排序、保存失败反馈、撤销、桌面与窄屏溢出。
- 临时真实文件系统上的新增、重启、删除、恢复、导出与原文件保护；测试不操作真实用户收藏。
- 完整回归、类型检查与构建；本机安装后确认今日/书架/回顾/收藏/统计五个命令可切换。

未来扩展：Canvas/Markdown 单向导出、导入预览与冲突合并、账号来源标记、标签、可靠多端操作日志。它们不属于 3.1.0 的已实现承诺。
