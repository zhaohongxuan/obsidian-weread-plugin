# Obsidian 修改反向写回微信读书

当前不支持，也不计划将同步生成的 Markdown 修改反向写回微信读书。维护者已确认本插件保持单向、覆盖式同步边界。

## 原因与边界

现有同步链路以微信读书为来源，获取划线/想法并重建本地笔记；它没有受支持、经过验证的远端写回流程。将其改为双向同步还需要稳定标识映射、版本与修改检测、冲突处理和删除语义，不能安全地把任意 Markdown 编辑直接解释为远端笔记修改。

这不是声称微信读书在任何环境下都不能写笔记，而是本插件当前明确不提供这项能力。用户自己的长期批注应写在独立笔记中，并引用同步内容；不要把修改同步生成文件作为保存个人内容的方式。

## 重新评估条件

只有维护者重新确认双向产品边界，且具备可验证的授权写入通路和完整冲突设计，才重新评估；不把它排为普通导出增强。
